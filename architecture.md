# DevPilot AI Architecture

This document describes the stack, data model, and high-level design of the **DevPilot AI** platform.

## 1. Stack Overview

- **Frontend**: React + Vite + TailwindCSS + Axios + React Query
- **Backend**: FastAPI + Python + SQLAlchemy + SQLite (Development) / PostgreSQL (Production)
- **AI Core**: Specialized AI Agents + Shared Skills + Vector Query Service (Local JSON persistence)

## 2. High-Level Design

```
User -> React Frontend -> FastAPI Backend -> Agent Orchestrator -> Specialized Agents -> Skills & Services -> SQLite/PostgreSQL
```

### Specialized Agents
1. **Repository Analyzer Agent**: Maps languages, dependencies, and structures.
2. **Code Review Agent**: Audits target file paths for clean code practices.
3. **Documentation Agent**: Automatically scaffolds markdown manuals and guides.
4. **Testing Agent**: Builds pytest suites and mock data recommendations.
5. **Repository Chat Agent**: Handles contextual QA using local TF-IDF similarity vectors.
6. **Project Health Agent**: Computes dynamic overall and categorical health scores.
7. **Security Agent (Custom)**: Runs deep static security scans.

## 3. Data Model (SQLAlchemy Entities)

- **User**: Authentication credentials.
- **Repository**: Stores code repositories, root paths, ingestion states, and summarizations.
- **RepositoryFile**: Stores parsed file structures, languages, and checksums.
- **AnalysisReport**: Serializes output summaries generated by the analyzer agent.
- **HealthMetric**: Persists current and historic documentation, testing, security, maintainability, and complexity metrics.
- **ChatSession & ChatMessage**: Stores history logs for repo QA chats.
- **EmbeddingRecord**: Manages indexing reference states.
